# 날씨요정 (WEATHER FAIRY) 디자인·인터랙션 계획

> 최종 수정일: 2026-08-05
> 이 문서는 최종 통합 화면의 **보이는 구조·사용 흐름·반응형 상태**를 고정한다.
> PDF 실습 요구사항과 제출 검증은 [pjt_계획.md](./pjt_계획.md)에서 관리한다.

## 1. 서비스 정의

**날씨요정(WEATHER FAIRY)**은 여행을 준비하는 사용자가 국내·해외 도시의 현재 날씨와 단기 예보를 빠르게 확인하고, 마음에 드는 도시를 저장해 지도에서 비교하는 여행 날씨 앱이다.

핵심 질문은 다음 세 가지다.

1. 지금 이 도시는 어떤 날씨인가?
2. 여행 가려는 날에는 무엇을 챙겨야 하는가?
3. 내가 저장한 여러 도시 중 어디가 여행하기 좋은가?

## 2. 확정한 비주얼 방향

### 분위기

- **키워드:** cybernetic, futuristic, calm, travel intelligence
- **기본 배경:** 거의 검은 딥 네이비
- **지도:** 얇은 시안 발광선의 세계 지도와 아주 약한 네트워크 점·격자
- **강조색:** 선택·저장 상태에만 절제된 바이올렛
- **금지:** 군사·감시·공격·위협 지도, 빨강/주황 경보 색, 과도한 패널·대시보드 느낌

### 브랜드와 타이포그래피

- 좌측 상단에 영문 로고 `WEATHER FAIRY`를 둔다.
- `FAIRY`는 `WEATHER`보다 약 25% 크게 하여 브랜드의 리듬을 만든다.
- 중앙에 큰 서비스명이나 설명을 두지 않는다. 지도와 검색이 주인공이다.

### 검색창

- `국내 / 해외` 토글 바로 아래, 화면 상단 중앙에 배치한다.
- 돋보기 아이콘과 `도시 또는 지역을 검색하세요` 안내 문구를 유지한다.
- 테두리는 **1~2px의 단일 시안 네온선**, 모서리 반경은 **8~10px**로만 살짝 둥글게 한다.
- 둥근 알약 모양, 모서리 장식, 꺾인 프레임, 노치·돌출·기계식 장식은 사용하지 않는다.
- 검색창과 지도 사이에는 넉넉한 여백을 둔다.

### 표현 토큰과 대비

- 글로우는 `기본 → hover/focus → 활성`의 세 단계만 사용한다. 빛 번짐이 정보보다 먼저 보이지 않게 한다.
- 본문·입력값·버튼 텍스트는 배경과 **최소 4.5:1 대비**를 목표로 한다. 회색 안내 문구도 실제 구현에서 읽을 수 있는 명도로 조정한다.
- 선택/저장/날씨 상태는 색만으로 전달하지 않는다. 별 채움, 핀 모양, 라벨, `aria-label`을 함께 사용한다.
- 영문 로고용 장식 폰트 한 종과 한글 본문용 가독성 폰트 한 종을 분리하고, 두 경우 모두 시스템 폴백을 명시한다.

## 3. 홈 화면 레이아웃

```text
좌측 상단: WEATHER FAIRY                         우측 상단: ☆ 즐겨찾기

                          [ 국내 | 해외 ]
                 [ 🔍 도시 또는 지역을 검색하세요 ]

                ── 충분한 숨 쉴 여백 ──

                  큰 사이버 세계 지도 + 도시 핀

  ◀  [서울] [도쿄] [파리] [뉴욕] [런던] [방콕] [시드니] [로마]  ▶
     (내가 저장한 즐겨찾기 도시만, 오른쪽 → 왼쪽으로 천천히 이동)
```

### 하단 즐겨찾기 도시 카드 띠

- 추천 도시 목록이 아니라 **사용자가 직접 저장한 도시만** 출력한다.
- 각 작은 카드에는 랜드마크 선 아이콘, 도시명, 현재 기온, 저장된 별을 표시한다.
- 카드 띠는 얇고 보조적인 정보다. 지도보다 강하게 보이면 안 된다.
- 자동 이동은 오른쪽에서 왼쪽 방향이며, 마우스 호버·키보드 포커스 때는 멈춘다. `prefers-reduced-motion` 사용자는 자동 이동을 하지 않는다.
- 카드 클릭은 그 도시를 선택하고 지도 중심을 해당 도시로 이동시킨다. 별 버튼은 저장 해제만 수행하며 카드 클릭 이벤트와 분리한다.

### 즐겨찾기 수에 따른 카드 띠 상태

- **0개:** 카드 띠 대신 `저장한 도시가 아직 없어요. 도시를 검색해 별을 눌러 보세요.`와 검색 유도 버튼을 표시한다.
- **1~4개:** 자동 이동 없이 정렬된 카드로 표시한다.
- **5개 이상:** 자동 이동 카드 띠를 사용한다. 실제 이전/다음 버튼과 일시정지 버튼을 제공하고, 호버·`focus-within`·`prefers-reduced-motion`에서는 정지한다.
- 무한 이동을 위해 복제한 카드는 키보드 탐색과 스크린리더에서 제외한다. 카드 본체와 별 버튼은 중첩하지 않는 형제 요소로 구현한다.

## 4. 핵심 인터랙션

### A. 즐겨찾기 핀 ON/OFF

우상단 `즐겨찾기` 버튼은 다른 페이지로 이동하지 않는 **지도 핀 표시 토글**이다.

| 상태 | 지도 | 버튼 | 하단 카드 |
| --- | --- | --- | --- |
| OFF (기본) | 저장 도시 핀은 숨김. 단, 검색으로 선택한 현재 도시는 계속 표시 | 외곽선 별 | 저장 도시 카드가 계속 표시 |
| ON | 저장한 모든 도시의 핀이 지도에 나타남 | 바이올렛 활성 별·은은한 발광 | 저장 도시 카드가 계속 표시 |

- 저장 핀에 마우스를 올리면 도시명·현재 날씨·온도가 작은 툴팁으로 나타난다.
- 핀을 클릭하면 그 도시를 선택하고, 작은 현재 날씨 카드가 표시된다.
- 즐겨찾기가 비어 있을 때 버튼을 누르면 빈 지도 대신 `저장한 도시가 아직 없어요. 도시를 검색해 별을 눌러 보세요.`를 안내한다.
- 사용자가 기능을 바로 이해하도록 화면 표기는 `즐겨찾기 핀`으로 하며, 상태에 따라 보조 문구 또는 툴팁에 `핀 보기` / `핀 숨기기`를 표시한다.
- 이 버튼은 실제 `button`으로 구현하고 `aria-pressed`로 ON/OFF 상태를 전달한다. 최소 터치 영역은 44×44px이다.
- 핀이 겹치면 클러스터로 묶고, 확대 또는 선택하면 개별 핀을 확인할 수 있게 한다.
- 지도 레이어 순서는 `기본 지도 → 즐겨찾기 핀 → 검색 선택 핀 → 툴팁/현재 날씨 카드`로 고정한다. 검색 선택 핀은 시안, 즐겨찾기 핀은 바이올렛과 별 라벨로 구분한다.
- 즐겨찾기 핀을 켤 때 저장 도시가 모두 국내에 있으면 해당 범위가 잘 보이도록 한국 중심으로, 해외 도시가 하나라도 있으면 저장 도시 전체가 보이도록 지도 범위를 맞춘다. 단, 상단 `국내/해외` 토글은 **검색 결과 범위만** 바꾸며 지도 범위를 제한하지 않는다.

### B. 도시 검색 → 지도 이동

```text
국내/해외 범위 선택
  → 도시명 입력
  → 자동완성 결과에서 도시 선택 또는 Enter 검색
  → Geocoding으로 좌표·국가·시간대 확정
  → 지도 flyTo(선택 도시가 중앙에 오도록 이동)
  → 현재 날씨 요청
  → 선택 핀 + 간단 날씨 카드 표시
```

- 입력 중에는 같은 이름의 다른 도시를 구별할 수 있도록 `도시명 · 국가/지역` 자동완성 목록을 제공한다.
- 국내 토글은 대한민국 도시 결과만, 해외 토글은 대한민국을 제외한 전 세계 도시 결과를 검색한다. 두 토글의 접근성 이름은 각각 `검색 범위: 국내`, `검색 범위: 해외`로 한다.
- 지도 이동 중에도 UI를 잠그지 않으며, 새 검색이 먼저 완료되면 이전 요청 결과는 버린다.
- 자동완성은 키보드 위·아래 화살표, Enter, Escape를 지원하는 combobox로 구현한다. Enter는 결과가 정확히 하나일 때만 선택하며, 여러 결과일 때는 목록 선택을 유도한다.
- 상태를 `자동완성 검색 중`, `결과 없음`, `좌표 확인 성공·날씨 요청 실패`, `지도 로드 실패`로 분리한다. 결과 목록 변화는 `aria-live="polite"`로 알린다.
- 간단 날씨 카드는 지도 위를 가리지 않는 위치에 다음을 표시한다.
  - 도시명·국가
  - 현재 날씨 아이콘·설명·현재 기온·체감온도
  - 저장/해제 별 버튼
  - `상세보기` 버튼

### C. 상세보기

- 간단 날씨 카드의 `상세보기`는 Router의 동적 경로(`/weather/:cityId`)로 이동한다.
- 해외 도시는 Geocoding 결과의 안정적인 ID와 좌표·시간대를 즐겨찾기 데이터에 저장해 다시 열 수 있게 한다.
- 상세 화면은 모바일에서도 한 열로 자연스럽게 쌓인다.

#### 상세 화면 정보 구조

1. **여행 날짜·모드:** 여행 날짜를 고르고 `평일 / 주말` 모드를 선택한다. 이 선택은 아래의 준비 요약을 반응형으로 갱신한다.
2. **현재 날씨:** 현재 기온, 체감온도, 상태, 습도, 바람, UV, 현지 시각, 업데이트 시각
3. **향후 5일:** 날짜·날씨 아이콘·최저/최고 기온·강수 확률·강수량
4. **시간대별 변화:** 기온과 강수량/강수 확률의 변화
5. **여행 준비 요약:** 평일에는 출퇴근 우산·옷차림을, 주말에는 야외 활동 적합도와 비 올 때의 실내 대안을 조건 기반으로 제안한다.
6. **먼 미래 여행:** 실제 예보 가능 범위를 넘으면 `예보`가 아닌 해당 월의 과거 기후 경향으로 명확히 표시한다.

## 6. 데이터 출처와 진실성 원칙

- OpenWeather: 국내·해외 도시 검색, 현재 날씨, 상세의 5일/3시간 예보와 대기질에 사용한다. API 상태 코드는 공통 날씨 아이콘 체계로 정규화한다.
- Open-Meteo Forecast/UV: `/forecast`의 16일 전체 예보·시간별·UV에만 사용한다.
- OpenWeather 기본 현재/5일 API에 없는 상세 UV는 `0`으로 대체하지 않고 `—`로 표시한다.
- 단기 예보와 과거 기후 평균을 혼동하지 않는다. 16일 이내만 실제 예보로 표시하고, 그 이후는 월별 기후 경향으로 라벨을 바꾼다.
- API 요청은 취소·요청 ID·짧은 캐시를 적용해 빠른 검색 시 오래된 응답이 화면을 덮지 않게 한다.
- 생성 시안은 **디자인 기준**으로만 사용한다. 실제 구현에서는 라이선스·출처 표기가 가능한 지도 라이브러리와 타일을 사용하며, 지도 위 핀·hover·`flyTo`·줌은 실제로 동작해야 한다.
- 선택 카드와 상세 화면에는 데이터 출처, 현지 시간대, 업데이트 시각을 작은 보조 정보로 표시한다.

## 8. 퍼블리싱·반응형·접근성 명세

### 화면 폭별 레이아웃

- **데스크톱(1024px 이상):** 지도 영역은 최소 500px, 화면 높이의 약 55~60%를 유지한다. 하단 카드 띠는 80~88px의 보조 영역으로 제한한다.
- **태블릿(768~1023px):** 검색창은 화면 폭에 맞춰 줄이고 지도는 최소 440px을 유지한다. 카드 띠에는 한 번에 3~4장을 보여 준다.
- **모바일(767px 이하):** 로고와 즐겨찾기 핀 버튼은 한 줄에 둔다. 토글과 검색창은 그 아래 전체 폭으로 배치하고, 지도는 최소 360px을 유지한다. 선택 도시 카드는 지도 아래 bottom sheet 영역으로 옮기며, 카드 띠는 자동 이동 대신 가로 스크롤·스냅으로 제공한다.

### 지도와 조작 규칙

- 툴팁은 `도시명·현재 기온·날씨 상태`까지만, 클릭 뒤 선택 카드는 `체감온도·저장 별·상세보기`까지 표시한다.
- 툴팁과 선택 카드는 반투명 배경만 사용하지 않는다. 충분한 대비의 딥 네이비 단색 배경과 테두리를 사용한다.
- 지도 조작이 어려운 사용자도 동일한 도시를 선택할 수 있도록 즐겨찾기 카드 목록을 대체 선택 수단으로 제공한다.
- 모든 아이콘 버튼은 최소 44×44px이며, 키보드 포커스는 hover 글로우와 구별되는 2px 이상 외곽선으로 표시한다.

### 최종 통합 화면의 Router 증빙

- 홈에는 큰 탭 내비게이션을 두지 않는다. 로고는 홈으로 이동하고, `상세보기`는 `/weather/:cityId`, 상세 화면의 뒤로 가기는 홈으로 이동한다.
- PDF Router·메뉴 실습의 원본 화면과 별도 메뉴는 기존 연습 코드에 보존한다. 최종 통합 화면은 위의 라우팅 동작과 404 화면으로 Router 사용을 확인한다.

## 9. 디자인 확인 체크리스트

- [ ] 로고가 좌측 상단에 있고 `FAIRY`가 조금 더 크다.
- [ ] 검색창은 장식 없는 얇은 네온 사각형이며 모서리만 살짝 둥글다.
- [ ] 검색창과 지도 사이에 충분한 여백이 있다.
- [ ] 지도는 화면의 주인공이고 하단 카드 띠는 작고 보조적이다.
- [ ] 하단 카드에는 추천 도시가 아닌 즐겨찾기 도시만 있다.
- [ ] `즐겨찾기` 버튼이 저장 핀 표시를 ON/OFF 한다.
- [ ] OFF여도 검색으로 선택한 도시는 지도에서 계속 확인할 수 있다.
- [ ] 검색 결과를 선택하면 지도가 해당 도시를 중앙으로 이동한다.
- [ ] 핀 호버에 현재 날씨 요약이 나타나고, 상세보기에서 5일 예보를 볼 수 있다.
- [ ] 로딩·빈 결과·API 오류·즐겨찾기 없음 상태가 디자인에 포함되어 있다.
- [ ] 키보드 조작과 `prefers-reduced-motion`을 확인했다.
- [ ] `국내/해외` 토글이 검색 결과만 바꾸며, 지도 범위와 혼동되지 않는다.
- [ ] 평일/주말 모드와 여행 날짜에 따라 여행 준비 요약이 달라진다.
- [ ] 데스크톱·태블릿·모바일에서 지도·검색·카드·선택 카드가 겹치지 않는다.
- [ ] 즐겨찾기 0개, 1~4개, 5개 이상과 핀 밀집 상태를 확인했다.
- [ ] 실제 지도 출처 표기, 지도 오류 시 대체 도시 선택, 최신 데이터 시각을 확인했다.
